# P4 橡皮擦改为"图层级"修正指令（Qoder）

## 背景（问题定位）
- 当前 `canvas/app.js` 的 `eraseStroke`（约 L334-368）用 `liveInstances().forEach(...)` **遍历所有未删除实例**，对每个与笔迹相交的实例都做布尔差擦除。
- 用户需求：**橡皮擦只擦"当前选中的实例"（图层级）**，不能把笔迹经过的其他实例一起擦掉。

## 需求改动
把 `eraseStroke` 的作用对象从"所有相交实例"改为"**仅当前选中实例**"：

1. **只擦选中实例**：
   - 取 `selectedInst()`（`state.instances.find(i => i.id === state.selectedId && i.mark !== "deleted")`）
   - 只对该实例做原有逻辑：外接框相交判断 → 栅格布尔差（destination-out）→ 擦光则 `mark="deleted"`（countEdit delete）→ 分裂出多个实例（保留原 id 最大块，其余新实例）→ `markModified` + `countEdit erase_mask`
   - **笔迹经过的其他未选中实例一律不动**

2. **无选中实例时**：
   - 不擦任何东西、不产生记录、不入撤销栈
   - 画布中央显示普通提示（**非错误红条**，用现有 hint 淡出机制即可）：「请先点选要擦除的实例」，约 2 秒淡出

3. **联动保持不变**：撤销/重做、修正计数、语义图刷新、检测框派生——均沿用现有实现，只是作用对象变成单个实例。

## 验收清单（逐项实测后汇报）
1. 图上有两个相交/相邻实例 A、B：**点选 A → 擦除笔迹同时经过 A 和 B → 只有 A 的掩码被擦，B 完好无损**
2. 不点选任何实例 → 擦除：界面出现"请先点选要擦除的实例"提示，**画布无任何变化，0 修正记录，无撤销步骤**
3. 擦除选中实例一部分 → 1 条 `erase_mask` 记录、1 条撤销；语义图/检测框联动正确
4. 把选中实例擦光 → `delete` 记录、实例标记 deleted、选中清空
5. 擦除后撤销（Ctrl+Z）→ 恢复，计数回退
6. 深色模式不变（当前浅色主题），提示条样式与现有一致
7. `git add -A` 前检查：不含 `data/images/`、`weights/`
8. 提交记录清晰，并更新 CONTEXT.md 当前状态（橡皮擦改为图层级）→ commit → push
