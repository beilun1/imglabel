# P4 修正指令：框模式下"框内空白处"无法新建检测框（大框罩住漏检目标）

## 现象（用户真实反馈，2026-10-18）
人工过审时发现：**床上面有一台笔记本电脑未被预标注识别到**（漏检），用户想在床的检测框内部新建一个电脑的检测框，但**按下左键拖拽永远变成"移动床的框"，无法新建**。

## 根因（已定位，canvas/app.js）
`hitTestBox(sx, sy, tol)`（约 L382-404）在框模式（box）下用**外接矩形包含**判定按下点是否命中实例：

```js
for (const inst of liveInstances()) {
  const bb = ptsBBox(inst.mask.points);
  if (w.x >= bb.x0 && w.x <= bb.x1 && w.y >= bb.y0 && w.y <= bb.y1) {  // 点在框内即命中
    const a = (bb.x1 - bb.x0) * (bb.y1 - bb.y0);
    if (a < bestArea) { best = inst; bestArea = a; }
  }
}
return best ? { kind: "box-move", inst: best } : null;
```

- 只要按下点在**任意实例的外接矩形内**（不管该像素有没有掩码），就返回 `box-move`（移动框）
- 只有点在**所有框外**才返回 null → 才能走 `box-create`
- 床的框很大，漏检的电脑落在床框内 → 按下必命中床 → 永远无法新建

## 修复要求（改 canvas/app.js，一处函数 + 光标联动）

### 1. 框模式命中判定：从"外接矩形"收紧为"掩码级"
改 `hitTestBox` 的框内命中分支：按下点**只有落在某实例的掩码内（或距掩码边 ≤3px 图像坐标容差）**才判定为 `box-move`；点在框内但**不属于任何实例掩码**（漏检目标、框与掩码间的空隙）→ 返回 null → 走 `box-create` 新建框。

具体做法：
- 保留现有逻辑顺序：选中框的**把手优先**（L384-392 不动）
- 命中循环里，先用 `pointInPoly([w.x, w.y], inst.mask.points)` 判断；不中再对掩码多边形各边做「点到线段距离 ≤3px」的容差判断（避免鼠标点在掩码描边外侧 1-2px 就误触发新建）
- 多个实例掩码同时命中（重叠，少见）时仍取**掩码外接矩形面积最小者**（保留"大框不挡小框"语义，避免床掩码挡电脑）
- 容差与把手 tol 一样做成参数默认值（如 `tol=3`），不写死魔法数散落多处

### 2. hover 光标同步
`pointermove` 里 L907-911 对 `hitTestBox` 的复用自动生效：框内非掩码区域光标恢复默认（十字/新建样式），掩码上仍是 move。检查 `updateCursor`/光标样式逻辑，确保"框内空隙"不再显示移动光标。

### 3. 明确不动
- `box-create` 的完整流程（pointerdown 初始化 editRect → pointermove 预览 → pointerup 建矩形实例 + `addInstance(...,"create")` 计数）**一律不动**
- `box-move`/`box-resize` 的移动/缩放、撤销快照、`countEdit("move"/"resize")` 计数、修正记录落盘**一律不动**
- 掩码模式（mask）的画笔/橡皮/多边形/移动命中（`hitTestMaskImg`）**一律不动**
- 语义模式、平移（空格/中键/抓手）、缩放**一律不动**
- 十类词表、计数口径、records 结构**一律不动**

## 自测清单（改完在 5001 隔离目录实测，逐项过）
1. 造一个"大矩形实例"（如床）+ 在它框内空白处放一张漏检目标图：**在床框内、床掩码外**按下拖拽 → 成功新建检测框，且 record 类型为 `create`
2. 点在床**掩码上**拖拽 → 仍是移动床（不新建）
3. 掩码描边外侧 2-3px 按下 → 仍判定为移动/选中该实例（容差生效，不误触新建）
4. 桌子上放杯子（小掩码叠在桌掩码上），点杯子 → 选中/移动**杯子**而非桌子（重叠取最小仍生效）
5. 选中框把手缩放 → 正常；撤销/重做 → 新建与移动均正常回退
6. 新建框保存 → `data/annotations/*.json` 落盘，刷新仍在，`modified_count` 与记录一致
7. 自测产生的标注与记录**只留在 5001 隔离目录**（临时 ANN/REC 目录），`data/annotations/`（含用户已过审修改）与 `data/records/修正记录.json` **md5 比对必须不变**——用**只按路径提交**（git add canvas/app.js 等具体文件），**不得 `git add -A`**，避免把用户在途的真实标注/记录混进提交
