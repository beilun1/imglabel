# P4 补充修正指令：框模式拆分为「移动」与「新建框」两个工具

> 本指令是对 `P4-框内新建指令.md`（已执行，提交 `b1f7a9b`）的补充。
> 背景：掩码级命中修好后，"框内空隙处新建"已生效；但**目标物体叠在另一个实例掩码上**（如床上的电脑、桌上的书）仍无法新建——按下点命中下层实例（床）的掩码 → 判定为移动。用户指定方案：**框模式拆成「移动」「新建框」两个工具**，需要新建时切到"新建框"工具，任何位置拖拽都可新建。

## 现象（用户实测确认，2026-10-18）
- 已 Ctrl+F5 强刷（新代码生效），框内空白处可新建 ✓
- 但**点在物体上（电脑在床掩码内）按下拖拽仍变成移动床，无法新建** ✗

## 改动要求（canvas/app.js + templates 列表页画布页）

### 1. 状态：box 模式增加工具
- `state` 增加 `boxTool: "move"`（`"move"` = 移动/选中/缩放；`"create"` = 新建框），**默认 `"move"`**
- 与掩码模式 `tool`（brush/eraser/polygon/move）并列，互不影响

### 2. 工具栏 UI（画布页模板）
- box 模式下显示两个工具按钮：「🖱️ 移动」「➕ 新建框」，当前工具高亮，点击切换；样式复用现有 `maskTools` 按钮风格（如不一致则保持画布页浅色主题一致即可）
- 快捷键：**N = 新建框**、**V = 移动**（框模式下生效；掩码模式下 V 已是"移动工具"，语义统一好记）；快捷键处理在现有键盘监听里加分支，注意 select/input 焦点例外规则（坑 ⑩ 不变）
- 引导文案（现有 "在图片空白处按住左键拖拽，创建检测框"）更新为："移动工具：点按掩码拖动/缩放手柄调整框；新建框工具（N）：任意位置拖拽创建新框"

### 3. pointerdown 行为（cvMain 事件，`state.mode === "box"` 分支）
- **`boxTool === "move"`**：保持现逻辑（`hitTestBox`：把手优先 → 掩码命中 → move/resize）；点空白（未命中）→ 仅 `state.selectedId = null`，**不新建框**
- **`boxTool === "create"`**：**跳过 `hitTestBox`，任何位置直接 `box-create`**（初始化 editRect = 按下点），拖拽预览、弹起建矩形实例（沿用 `endPointer` 里现有 box-create 收尾：尺寸阈值、`addInstance(...,"create")` 计数、撤销——**一律不动**）
- 平移（空格/中键/抓手 `canPan`）在两个工具下都保持可用，优先级不变（pan 判断在前）

### 4. pointermove / 光标
- `boxTool === "create"` 时 hover 光标显示新建样式（十字，与画笔光标圈风格一致即可）；`"move"` 保持现状（move / 把手样式）
- 拖拽预览、缩放、移动逻辑全部沿用现有代码，不改

### 5. 明确不动
- `hitTestBox`（掩码级判定）保留，作为"移动工具"的命中逻辑
- box-create 流程、`addInstance`、`countEdit("create"/"move"/"resize")`、撤销/重做、records 落盘、修正率口径——**全部不动**
- 掩码模式（画笔/橡皮/多边形/移动）与语义模式——**不动**
- 十类词表、计数口径、records 结构——**不动**
