# P4 修正指令：多框重叠时"连续点击循环切换"选中（大框不挡小框 + 可选中大框）

> 本指令在 `P4-移动选中修正指令.md`（框级命中）基础上增加**重叠框循环切换**。
> 现状：重叠处永远选中面积最小的框，想选大框必须点它框内不重叠的区域，目标叠在中央时别扭。
> 用户选定方案：**重叠处连续点击，在重叠框之间循环切换选中**（业界标注工具标准做法）。

## 现象/需求（用户确认，2026-10-18）
- 床上电脑、桌上杯子这类"小框完全叠在大框内"的场景，点击默认选中小框（合理）
- 但当用户**想选大框**（床/桌）时，需要专门点非重叠区域，体验别扭
- 要求：在重叠处**连续点击**即可依次选中 小框 → 次小框 → … → 大框 → 回到小框（循环）

## 改动要求（canvas/app.js，移动工具命中与 pointerdown）

### 1. 命中收集：`hitTestBox` 返回命中列表而非单个
- 改为返回**按外接矩形面积升序排列**的全部命中实例数组（`[{inst, kind:"box-move"}, ...]`），最小框在前；把手命中仍单独优先（返回单个 box-resize）
- 现有调用方（pointerdown 移动分支、pointermove 光标）相应适配：
  - 光标：命中列表非空即显示 move 光标（不变）
  - pointerdown 移动分支：按下方"轮换规则"从列表中选目标

### 2. 轮换规则（pointerdown，移动工具，无拖动的单击场景）
- 命中列表长度 == 1 → 选中该框（现状）
- 命中列表长度 ≥ 2：
  - 若**当前选中实例在命中列表中** → 选中列表里它**下一个**（更大者）；已是最大框 → 回到列表第一个（最小框）
  - 若当前未选中、或选中者不在命中列表中 → 选中列表第一个（最小框）
- **拖动判定不变**：pointerdown 后按住拖动（pointermove 超阈值）→ 移动**本次选中的框**；轮换只在每次 pointerdown 时决策一次，与拖动互不冲突
- 可选加分（实现简单则做）：按住 **Alt + 点击** 强制轮换到下一个；不做也不影响主规则

### 3. 提示（可选，增强可用性）
- 命中列表 ≥2 时，状态栏/画布轻提示（如 `flashHint`："N 个框重叠，点击切换"），或选中标签旁显示"（重叠 N，点击切换）"；提示要轻量，不打扰

### 4. 明确不动
- 新建工具（`boxTool==="create"`）任意位置新建——不动
- 框级命中判定（外接矩形包含、掩码级不再使用）——不动
- 拖动移动、把手缩放、`countEdit("move"/"resize")`、records 落盘、撤销/重做——不动
- N/V 快捷键、两个工具按钮、`setBoxTool`——不动
- 掩码模式/语义模式、十类词表、计数口径——不动

## 自测清单（5001 隔离目录实测，逐项过）
1. 两个框重叠：重叠处**连续点击** → 依次选中 小框 → 大框 → 小框（循环）
2. 三个框重叠：小 → 中 → 大 → 小（循环）
3. 不重叠区域点击 → 直接选中对应框（轮换不误触发）
4. 点所有框外空白 → 取消选中
5. 选中后按住拖动 → 移动的是**当前选中的框**（轮换后拖动大框=移动大框）
6. 把手缩放、撤销/重做、平移、新建工具（N）全部正常
7. 保存 → `data/annotations/*.json` 落盘、刷新仍在、`modified_count` 与记录一致
8. 自测数据只留在 5001 隔离目录（临时 ANN/REC 目录），`data/annotations/` 与 `data/records/修正记录.json` **md5 比对不变**；**只按路径提交**（git add canvas/app.js 等具体文件），**不得 `git add -A`**
