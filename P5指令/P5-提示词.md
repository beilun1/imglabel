## 任务 1：三格式导出脚本 `export_dataset.py`（源码根）

从 `data/annotations/` 全部 327 个 JSON + `data/curated/images/` 原图，导出到 **`dataset/`**（任务书规定目录名，平台导出结果）：

### 1a. 导出前校验（前置条件，不通过就停止并修复）
- 运行 `python tools/records_stats.py`，确认「一致性 通过」（每图记录条数 == JSON `modified_count`；被记录实例 id 集合 == `mark≠unchanged` 的实例集合）
- 任何不一致 → 先排查（多半是记录与 JSON 不同步），**不得带着不一致导出**

### 1b. 导出内容（每张图输出到 `dataset/`）
- **图片**：复制原图到 `dataset/images/`（文件名不变，jpg）
- **YOLO txt（检测）**：`dataset/labels/*.txt`，每行 `cls xc yc w h`（类别编号 0-9，中心点与宽高均归一化到 [0,1]）；框 = 实例掩码的外接矩形（轴对齐 min/max）
- **实例掩码（分割）**：`dataset/segments/*.txt`，每行 `cls x1 y1 x2 y2 ...`（归一化多边形顶点序列，取掩码外轮廓；掩码可能含孔洞与 `src:"det"` 的 4 点占位框，按 YOLO seg 惯例只导外轮廓即可，孔洞不表达）
- **语义 PNG**：`dataset/semantic/<图名>.png`，像素值 = 类别编号 + 1（背景 0，类别 1-10），由实例掩码按类合并填充（同类多实例并集，后画的覆盖先画的，顺序稳定即可）
- **划分**：train/val 按 **9:1** 随机划分（随机种子固定，如 42），生成 `dataset/train.txt`、`dataset/val.txt`（每行一张图片路径，绝对或相对 dataset 根均可，train.py 与 train.py 同一口径即可）；**所有 327 张都进 train 或 val，不许丢图**
- 导出规则：
  - **跳过 `mark=="deleted"` 的实例**（软删除，数组里还在但必须排除）
  - 空图（实例全被删/本来就空，如 coco_14831/coco_274687/coco_776/coco_99428）→ 检测/分割 txt 为空文件，语义 PNG 全 0，仍然导出并计数
  - 类别编号 = 十类词表顺序（0-9），**不得改**
  - 坐标用浮点数，保留 6 位小数；越界 clip 到 [0,1]
- **输出统计**：打印导出总图数、有效实例数、每类实例数、空图数、train/val 数，写入 `dataset/export_report.md`（含每类数量，P6/P7 要用）

### 1c. 可复用性
- `python export_dataset.py [--out dataset] [--seed 42]`，可重复运行且结果确定（覆盖导出）；对已存在文件直接覆盖，无需幂等跳过（导出是派生物，随时可重生成）

## 任务 2：`train.py`（源码根，任务书红线：只接受平台导出数据集）

- 只读 `dataset/`（任务 1 的导出物）；**绝不直接吃 `data/annotations/` 或别的格式**，违反即违规
- 用 **ultralytics YOLO26n-seg**（`weights/yolo26n-seg.pt` 为起点微调）：
  - 检测分支 + 分割分支都在一次训练里完成（YOLO26n-seg 自带双头，检测用 `dataset/labels`、分割用 `dataset/segments`，语义 PNG 不用于训练，仅交付物）
  - 数据配置写成 `dataset/data.yaml`（train/val 路径、nc=10、names=十类英文名）
- **自动检测配置选训练参数**（任务书要求）：CPU → epochs 较小（如 30，先跑通）、imgsz=640、batch=4（内存不够再降）；有 GPU → epochs 可加大（如 60+）。参数集中在文件顶部常量，注释说明选择依据（ADR 留痕）
- 训练输出：`model/best.pt`（ultralytics 结果里挑 best），`model/` 目录不存在则创建；同时保留训练结果目录 `runs/`（不进 git 无所谓）
