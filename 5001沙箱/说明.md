# 5001 隔离沙箱

在 `%TEMP%\isolated_5001` 建一份项目副本，用 5001 端口启动。可以随意预标注、改标注、录 demo，真实项目（5000 服务、`data/`、`dataset/`、`model/`）完全不受影响。

| 文件 | 作用 |
|---|---|
| `5001隔离启动.bat [demo-展示\|demo-预标注]` | 重建副本并启动 5001，默认 `demo-预标注` |
| `5001隔离reset.bat` | 清空副本的 `data\annotations\*.json` 与 `data\records\*.json`，可反复预标注 |
| `读取副本统计.ps1 [-Path 副本目录]` | 汇总副本标注：图名 / 阈值 / 实例数 / conf 的 min·avg·max |

## 两种模式

| | demo-展示 | demo-预标注 |
|---|---|---|
| 图片 | 前 20 张（文件名顺序） | 前 8 张 |
| 标注 JSON | 拷同名 JSON（现成标注） | 空 |
| 修正记录 | 空 | 空 |
| 权重 | 不拷（预标注页不可用） | 拷 `weights/` 全部（`yolo26n-seg.pt`、`yolov8s-worldv2.pt`、`clip/ViT-B-32.pt`） |
| 用途 | 录仪表盘、列表、画布操作 | 录预标注、做阈值对比 |

两种模式的共同点：
- 代码用 robocopy 镜像过去，排除 `weights data dataset runs __pycache__ .git .workbuddy`。
- 每次启动都会重建副本的 `data/`，所以上一次的改动不会保留。
- 启动前会检查 5001 端口。端口被占用就报错退出，并打印占用进程的 PID，**不会自动结束任何进程**。
- 用 `C:\Users\H\miniforge3\envs\imglabel\python.exe -c "import app; app.app.run(port=5001)"` 启动。按 Ctrl+C 停止。

> `clip/ViT-B-32.pt`（354MB）是 YOLO-World `set_classes` 用的文本编码器。不拷的话，副本会尝试联网下载。

## reset 为什么能反复预标注

`prelabel.run` 和 `/api/prelabel` 是幂等的：已有 JSON 的图直接跳过，记作 skipped。

`reset` 删掉副本里的 JSON 后，所有图重新变回"未标"。这时再点预标注就会全部重跑，可以换一个阈值得到新结果。

`reset` 只动 `%TEMP%\isolated_5001`，不会碰真实项目。预标注运行中不要 reset。

## 三种用法

### A 预标注阈值对比

1. 运行 `5001隔离启动.bat demo-预标注`，浏览器打开 http://127.0.0.1:5001
2. 预标注页设阈值 0.1 跑批（可限张 1–2 张），然后在另一个窗口运行 `powershell -ExecutionPolicy Bypass -File 读取副本统计.ps1`
3. 运行 `5001隔离reset.bat`，阈值改为 0.25 跑批，再统计
4. 运行 `5001隔离reset.bat`，阈值改为 0.6 跑批，再统计

期望结果：实例数随阈值单调递减，且每档的 min(conf) ≥ 该档阈值。

实测（2026-10-26，限 2 张：coco_10092 + coco_102707）：

| 阈值 | 实例数 | min(conf) | avg(conf) | max(conf) |
|---|---|---|---|---|
| 0.10 | 15 | 0.153 | 0.296 | 0.795 |
| 0.25 | 5 | 0.329 | 0.484 | 0.795 |
| 0.60 | 2 | 0.671 | 0.733 | 0.795 |

### B 画布功能自测

运行 `5001隔离启动.bat demo-展示`，在 20 张带现成标注的图上直接测试新建、移动、擦除、撤销/重做、保存。保存只写进副本，真实标注不变。

### C demo 录制

- 录画布操作：用展示模式。
- 录预标注和阈值对比：用预标注模式，**每次开录前先 reset**，确保从"未标"开始。

端口固定为 5001，可以反复录。录完按 Ctrl+C，然后删除副本：`rd /s /q "%TEMP%\isolated_5001"`

## 录 demo 可行性

Qoder 只提供脚本和说明，不负责录像。用 OBS 或系统录屏（Win+G / Win+Alt+R）即可。这套流程适合录 demo，原因如下：

- **隔离**：副本在 `%TEMP%`，5000 正式服务照常运行。
- **可复现**：每次启动重建同一批图（前 20 / 前 8 张）。
- **可反复**：reset 后可以重新预标注，录坏了就重来。
- **零污染**：真实数据五组 MD5 不变（已验证）。

建议步骤：
1. 关掉浏览器多余标签页。
2. 启动对应模式。
3. 预标注模式先 reset。
4. OBS 选浏览器窗口开录。
5. 录完停止服务，删除副本。

## 红线

- 真实 `data/annotations`、`data/records`、`dataset`、`records`、`records/对比结果.csv` 这五组 MD5 不受影响。自测时在用后删副本的前后各做一次对比，结果一致。
- 只按路径提交本目录的文件，不用 `git add -A`。副本在 `%TEMP%`，不进 git。
- 不改 `app.py` / `prelabel.py` / `reback.py` / `train.py`，不动 5000 服务，不自动杀进程。

## 备注

- **两个 .bat 是 GBK(936) 编码，且没有 `chcp 65001`。** cmd 按 UTF-8 读批处理时，中文行会错位成乱码命令。请不要另存为 UTF-8。
- `.ps1` 是 UTF-8 BOM 编码（兼容 PowerShell 5.1）。
- 模式参数也可以用 ASCII 别名：`demo-show` / `demo-prelabel`。
- 设置环境变量 `NO_PAUSE=1` 后，脚本结束或出错时不会 `pause`，供自动化测试使用。
- 可调参数在启动脚本开头：`GALLERY_N=20`、`PRELABEL_N=8`、`PORT=5001`、`PY=...`。
