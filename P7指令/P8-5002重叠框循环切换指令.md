# P8 补充 · 5002 重叠框循环切换（连续点击切换下一个框）

> 目标：在 5002 演示台画布上，**同一位置连续点击**时，可在重叠的多个检测框/掩码之间**循环切换**选中项，
> 解决"重叠框只能选中最上层、下面点不出来"的问题。
> 只改 `playground/static/app.js` 一个文件。**禁止改动 5000 的任何文件**（5000 已有该能力，不要动它）。

---

## 一、问题现状（已核实）

`playground/static/app.js` 第 625–651 行 `handleCanvasClick()` 当前逻辑：

```js
for (let index = instances.length - 1; index >= 0; index -= 1) {
  const instance = instances[index];
  const path = state.view === 'boxes' ? null : pathOf(instance);
  const box = bboxOf(instance);
  const hit = path ? hitContext.isPointInPath(path, x, y, 'nonzero')
                   : box && x >= box.x && x <= box.x + box.width && y >= box.y && y <= box.y + box.height;
  if (hit) {
    selectInstance(index);
    return;      // ← 命中即返回：永远只选到"最上层"那一个
  }
}
selectInstance(-1);
```

**根因**：遍历从上层到下层，命中第一个就 `return`，下层重叠实例永远没有机会被选中。

---

## 二、改造方案

### 2.1 核心思路

1. **收集全部命中**：不再命中即返回，而是把该点命中的所有实例索引收集成候选数组 `candidates`（顺序：上层 → 下层）。
2. **同位置循环**：记录"上一次点击的屏幕坐标 + 候选数组 + 当前选中位置"。
   - 若本次点击位置与上次**在同一处**（容差 ≤ 8 屏幕像素），且候选数组内容未变 → 取 `candidates[(上次位置 + 1) % 长度]`，即向下一层切换，到底后回到最上层。
   - 若位置变化或候选数组变化 → 取 `candidates[0]`（最上层），行为与现在一致。
3. **空白处点击**：清空选中并重置循环状态。

### 2.2 状态字段

在 `state` 对象（第 44 行附近）新增：

```js
clickCycle: { x: null, y: null, indices: [], pos: -1 },
```

- `x / y`：上次点击的**屏幕坐标**（`event.clientX / clientY`，未做图像坐标换算，容差判定更直观）
- `indices`：上次命中的候选实例索引数组（上层→下层）
- `pos`：上次选中的位置（在 `indices` 中的下标）

### 2.3 参考实现

将 `handleCanvasClick()` 替换为：

```js
function handleCanvasClick(event) {
  if (!state.transform || !state.image || !hitContext) return;
  const rect = ui.canvas.getBoundingClientRect();
  if (!rect.width || !rect.height) return;
  const transform = state.transform;
  const screenX = (event.clientX - rect.left) * transform.viewportWidth / rect.width;
  const screenY = (event.clientY - rect.top) * transform.viewportHeight / rect.height;
  const x = (screenX - transform.offsetX) / transform.scale;
  const y = (screenY - transform.offsetY) / transform.scale;

  const resetCycle = () => { state.clickCycle = { x: null, y: null, indices: [], pos: -1 }; };

  if (x < 0 || y < 0 || x > transform.width || y > transform.height) {
    selectInstance(-1);
    resetCycle();
    return;
  }

  const instances = instancesOf(activeResult());
  const candidates = [];
  hitContext.setTransform(1, 0, 0, 1, 0, 0);
  for (let index = instances.length - 1; index >= 0; index -= 1) {
    const instance = instances[index];
    const path = state.view === 'boxes' ? null : pathOf(instance);
    const box = bboxOf(instance);
    const hit = path ? hitContext.isPointInPath(path, x, y, 'nonzero')
                     : box && x >= box.x && x <= box.x + box.width && y >= box.y && y <= box.y + box.height;
    if (hit) candidates.push(index);          // 收集而非返回
  }

  if (!candidates.length) {
    selectInstance(-1);
    resetCycle();
    return;
  }

  const cycle = state.clickCycle;
  const sameSpot = cycle.x !== null
    && Math.hypot(event.clientX - cycle.x, event.clientY - cycle.y) <= 8;
  const sameSet = cycle.indices.join(',') === candidates.join(',');

  let pos = 0;
  if (sameSpot && sameSet) {
    const prev = cycle.indices.indexOf(state.selectedIndex);
    if (prev >= 0) pos = (prev + 1) % candidates.length;   // 切到下一层，到底回到最上层
  }

  selectInstance(candidates[pos]);
  state.clickCycle = { x: event.clientX, y: event.clientY, indices: candidates, pos };
}
```

### 2.4 循环重置点（必须全部覆盖）

| 时机 | 位置 | 处理 |
|---|---|---|
| 点击空白/越界 | `handleCanvasClick` 内 | 已在上方实现 |
| 切换图片 | `selectImage()` 第 260 行附近 / `state.selectedIndex = -1` 处 | 追加 `resetCycle()`（或直接赋 `state.clickCycle = {...}` 初始值） |
| 切换视图（框/掩码/语义） | `setView()` 第 653–669 行 | 追加重置 |
| 重新检测/清空结果 | `state.selectedIndex = -1`（第 794 行）、`resetResults` 处理 | 追加重置 |

> 重置后不会影响正常单点选中：位置变化时 `pos` 恒为 0，仍选最上层。

### 2.5 三视图一致性

- **检测框视图**（`boxes`）：用 `bbox` 外接矩形命中 → 重叠框连续点击可循环。
- **实例掩码视图**（`instances`）：用 `isPointInPath` 多边形命中 → 重叠掩码连续点击可循环。
- **语义分割视图**（`semantic`）：同样走 `pathOf` + `isPointInPath`，循环逻辑一致；注意语义视图同类同色，切换效果靠右侧列表高亮 + 详情面板序号变化体现，属正常。
