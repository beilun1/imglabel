## 1. 铁律（任何改动必须守，违反即返工）
- **不改数据**：`data/annotations/*.json`、`data/records/修正记录*.json`、`dataset/` 一律只读，严禁改动或重写
- **不动标注核心逻辑**：`canvas/app.js` 中三模式（检测框/实例掩码/语义）、工具（画笔/橡皮/多边形/移动/抓手）、撤销重做、修正计数埋点 `countEdit`、保存/加载 —— 这些只允许**包一层视觉样式**，禁止改行为
- **不改端口、不改 `app.py` 的既有 API 语义**（`/api/prelabel`、`/api/images`、`/api/annotation`、`/api/records/summary` 的返回结构不得变）
- **可新增路由**：但新 API 必须是**只读**或对既有数据的**幂等扩展**，不能破坏现有调用
- 静态资源继续走 `Cache-Control: no-store`，改完用户 Ctrl+F5 生效
- 提交前 `git add -A` 必看 status：不得含 `dataset/`、`runs/`、`weights/`、`data/images/`、`.workbuddy/`

## 2. 页面与路由规划（新增为主，改造现有）

### 2.1 仪表盘（新增首页，`GET /` 改为此）
- 改造现有 `index.html` 首页 → 仪表盘看板：
  - 左侧深色侧边栏：仪表盘 / 图片列表 / 标注画布 / 预标注 / 迭代对比 / 数据导出
  - 顶栏：面包屑「工作台 / 仪表盘」+ 右侧「本轮过审 X 张 · 累计修正 Y 条」（来自 `/api/records/summary`）
  - 4 张统计卡（白卡+左细色条）：**总图片数 / 已过审 / 累计修正 / 人工修正率**，数据来自现有 API 真实值，不要硬编码演示数
  - 「标注进度」进度条组（已过审 233/324、修正达标、预标注覆盖） + 「操作入口」快捷卡片
- 顶栏**不要**用户头像/账号（用户明确不要），只保留统计和入口

### 2.2 图片列表（新增页，`GET /annotate` 渲染卡片图库）
- 保留现有图片列表的全部信息（328→324 张、每张状态徽章），改造成**卡片网格**：
  - 顶部筛选胶囊：全部 / 已过审 / 回标草稿 / 已修改 / 未标
  - 卡片 = 缩略图 + 状态徽章（已过审✓绿 / 已修改橙 / 回标草稿 / 预标 / 已标） + 下方 图名·实例数
  - 分页控件
- 点击卡片 → 进入 `annotate/{name}` 画布

### 2.3 标注画布（改造现有，`annotate.html`）
- **布局重排但逻辑保留**：
  - 顶部工具条：返回按钮 + 文件名/序号 + 三模式切换（检测框/掩码/语义）+ 工具（画笔/橡皮/多边形/移动）+ 类别下拉 + 笔刷滑块 + 撤销/重做 + 保存(S)
  - 中部大画布区（深色底 `#1c2026`，让标注框更突出）
  - 画布右上角 10 类颜色图例
  - 右侧信息面板：选中实例详情（类别/ID/置信度/掩码点数）+ 修正计数（本图已改 X 处 → 落盘，累计 Y/60）+ 快捷键提示
- **必须保留完整功能**：三模式联动、工具、撤销重做、S 保存、`countEdit` 埋点。只改 show 层

### 2.4 预标注页（新增页，`GET /prelabel`）
- 左栏模型配置：
  - 检测模型下拉 → `YOLO-World（R0 · 官方权重）` / `YOLO-World（R1 · 微调自训）`（同一检测器的两个版本：R0 用官方原始预训练权重，R1 用你微调后的自训权重；**不得写成 `best.pt（R1）`**，避免被误读为换了另一个模型）
  - 实例分割模型显示（只读显示 `YOLO26n-seg`）
  - 类别词表（只读显示 10 类）
  - 置信度阈值滑块（默认 0.25）
  - **本次张数**输入框（留空=全部，正是现有 `/api/prelabel` 的 `limit` 参数支持的）
- 右栏：进度条 + 统计（新建/跳过/实例/失败）+ 纵向滚动日志框（显示当前处理文件名与实例数）
- 动作：开始预标注 / 取消。轮询复用现有 `/api/prelabel/status`

### 2.5 迭代对比页（新增页，`GET /compare` 或 `/results`）
- 展示 `data/records/对比结果.csv`（R0 vs R1 两行的真实数据）：
  - 柱状对比卡：**人工修正率**（23.8%→15.2%，标 ▼8.5%）、**分割 mAP50-95**（0.444→0.498，标 ▲0.054）、**检测 mAP50**（0.762→0.760，标 ≈持平）
  - 全指标一览表：修正条数 285→96、过审张数 153→83、整体修正率、auto 修正率
- 数据需从 CSV / 现有汇总接口读取，**不得硬编码**（虽然当前就是这些值，但要写成从数据源读）

### 2.6 数据导出页（新增页，`GET /export`）
- 左栏：三格式勾选（YOLO 检测 labels/ · 实例掩码 segments/ · 语义 PNG semantic/，三项都必选）+ 划分设置（train/val 比例、种子）+ 导出按钮
- 右栏：导出报告（各目录文件数 ✓ / 有效实例数 / 空图数 / 校验通过）+ dataset/ 目录清单
- 提示：导出可能耗时，给出进度/完成反馈

### 2.7 侧边栏
- 六个入口在所有页保持一致的深色侧边栏，当前页高亮

## 3. 视觉基准（对齐 UI设计稿.html）
