# P7 功能增强指令：预标注「一次标 N 张」限张控制（Qoder）

> 用途：本系统「开始预标注」目前默认一键全量（处理全部**没有 JSON 的初始待标图**）。
> 用户要在录制 demo 时演示"一次只标几张某张数（3-5 张）"的初始预标注。
> 前提：demo 用 3-5 张「尚无 JSON」的室内图临时放入 `data/curated/images/`（未标注 → 会被当待标新图），
> 本指令让页面能指定"本次只标前 N 张待标图"，从而把 demo 限定在这 3-5 张上。
> 红线：不得覆盖任何已有 JSON 的图；不改十类词表；不破坏幂等。

## 背景事实（已核验，2026-10-19）
- 后端：`app.py` `POST /api/prelabel` 只接收 `conf`，调用 `_prelabel_worker(conf)` → `prelabel.run(conf=conf, on_progress=...)`（app.py L168/L177/L189-206）
- `prelabel.run(names=None, conf=...)` 已支持传入**要处理的图名列表**（prelabel.py L177）；`run` 内部对**已有 JSON 的图一律跳过**（prelabel.py L191），只有无 JSON 的图才会被推理
- `prelabel.list_images()` 返回全部 jpg（含已标与未标），排序为 `sorted(os.listdir(IMG_DIR))`（prelabel.py L69-71）
- 前端：`templates/index.html` L13-17 预标注区（按钮+进度条+消息），L69-81 点击时 `fetch("/api/prelabel", {..., body:"{}"})`，body 为空对象

## 改动要求

### 1. 后端 `app.py`：`/api/prelabel` 接收 `limit`，并传给 worker
- `POST /api/prelabel` 请求体新增可选 `limit`（整数）：**唯一合法语义 = 本次只处理未标图中前 limit 张**（limit 省略或 ≤0 表示不限/全量，保持向后兼容）
- 解析：`limit = body.get("limit"); try int, 非法或 None 或 <=0 → None（全量）`
- `_prelabel_worker` 增加 `limit` 参数：
  - 传入前先取 `prelabel.list_images()`，筛出**无对应 JSON** 的图（存在 `data/annotations/{name}.json` 才算有），得到"待标图列表"；若 limit 非空，截取 `待标图前 limit 张`
  - 将该列表作为 `names` 传给 `prelabel.run(names=names, conf=conf, on_progress=...)`
  - 统计口径不变：`total` 应为**本次实际要处理的张数**（≤ limit，也≤待标总数）
- **明确不做**：不做暂停/取消、不引入 run 内部状态机；只做"限张"这一个控制

### 2. 前端 `templates/index.html`：预标注区加"本次张数"输入框
- 在「开始预标注」按钮（L14）左侧加一个数字输入框，旁注"本次张数（留空=全部）"：
  - `<input type="number" id="prelabelLimit" min="1" placeholder="全部" style="width:90px"> `
- 点击按钮时（L73）把该值带进请求体：
  ```js
  const limitVal = (document.getElementById("prelabelLimit").value || "").trim();
  body = limitVal === "" ? {} : { limit: parseInt(limitVal, 10) };
  fetch("/api/prelabel", { method:"POST", headers:{"Content-Type":"application/json"}, body: JSON.stringify(body) })
  ```
- 输入校验：非正整数 → 视为空（全量）；输入 > 待标总数时按实际待标数处理（后端自然截断）
- 进度条/消息渲染（L41-55）保持现状，不做其他改动
- 样式与现有浅色主题一致

### 3. 明确不动
- `prelabel.py` 的 `run`/`prelabel_image`/`list_images` 逻辑本身不改（只从 app.py 传 names）
- 十类词表、conf 默认、幂等跳过、三格式导出、records 计数、画布逻辑——全部不动
- 不做暂停/取消功能

## 自测（5001 端口隔离目录，或"临时戳入未标演示图后建 5001 目录实测"）
1. 准备 4 张无 JSON 的 test 图（可临时复制到隔离 ANN/REC 对应图目录），limit=2 → 只处理 2 张，其余 2 张不受影响
2. 点「开始预标注」，输入框留空 → 行为与改动前一致（全量，已有 JSON 跳过）
3. 输入 limit=3，但仅 2 张待标 → total=2，不报错不超量
4. 输入非法（0/负数/abc）→ 按全量处理，不崩溃
5. `POST /api/prelabel` 不带 limit（body `{}`）→ 与旧逻辑完全一致（回归）
6. 已过审/已标图即使在前 N 也被跳过（幂等不破坏）
7. 自测只在隔离目录（临时 ANN/REC 目录），`data/annotations/` 与 `data/records/修正记录.json` **md5 不变**
8. **git 提交按路径**：只提交 `app.py`、`templates/index.html`；不得 `git add -A`
