# P8 · 5002 任意图检测演示台（独立端口 · 进阶版）

> 定位：独立于 5000/5001 的演示台，**不绑定固定数据集**，任意图片拖入即可当场跑检测+分割，用于 demo 结尾展示系统可扩展性。
> 端口：5002（独立 Flask 进程）
> 红线：**不得改动 5000 项目的任何源码、数据、权重、records、dataset**。所有新文件放在独立目录内。

## 二、后端（playground/app.py）

### 2.1 路由

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | `/` | 返回主页 |
| POST | `/api/upload` | 接收上传图片（支持多张），返回 task_id + 图片列表 |
| POST | `/api/detect` | 触发异步检测（参数：task_id, model=R0/R1, conf=0.25） |
| GET | `/api/progress/<task_id>` | 轮询进度：pending/running/done + 每张图的结果 |
| GET | `/uploads/<filename>` | 返回上传原图（前端展示用） |

### 2.2 异步推理

- 使用 `threading.Thread` 后台跑，不阻塞请求。
- 任务状态存内存字典：`_tasks = {task_id: {status, images[], results[], progress}}`。
- **R0 推理**：调用主项目 `prelabel.run(names=图片路径列表, conf=阈值, on_progress=回调)`，取每张图的检测+分割结果。
  - 注意：`prelabel.run()` 会往 `ANN_DIR` 写 JSON——**调用前必须临时把 ANN_DIR 重定向到 playground 自己的临时目录**，绝对不能写主项目 `data/annotations/`。
  - 做法：在调用 `prelabel.run()` 前，用 `monkeypatch` / 环境变量 / 或复制一份 `_prelabel_patch.py` 包装，将输出路径改到 `playground/_tmp_results/`。
- **R1 推理**：用 `reback.load_model()` 加载 `model/best.pt`，对每张图直接 `model.predict(conf=阈值)`，结果从推理结果中解析。
- 每张图结果结构：
  ```python
  {
    "image": "xxx.jpg",
    "width": 640,
    "height": 480,
    "instances": [
      {"cls": 0, "cls_name": "person", "conf": 0.893,
       "bbox": [x1,y1,x2,y2],
       "mask": [[x,y], [x,y], ...]}  // 归一化或像素坐标二选一，与前端统一
    ]
  }
  ```

### 2.3 安全红线

- ❌ 绝对禁止写入主项目 `data/`、`records/`、`dataset/`、`model/`、`weights/`。
- ❌ 禁止修改 `prelabel.py` / `reback.py` / `app.py`（主项目）。
- ✅ 只读引用主项目的模型权重和推理函数。
- ✅ 所有上传文件、临时结果、缓存都在 `playground/` 内部。

## 三、前端（playground/templates/index.html + static/）

### 3.1 页面布局

沿用 5000 的 V2 克制风格：
- **左侧深色侧边栏**（#1a1d24）：顶部 LOGO 文字「YOLO 演示台」，下方菜单项：图片检测（高亮）、关于
- **右侧主区域**：白色卡片浮于浅灰底（#f5f6f8）
- 主色靛蓝 #2f6fe4，数字等宽字体 SF Mono / Consolas

### 3.2 主区域结构（从上到下）

**① 上传区（占满宽度，大虚线框）**
- 大图标 + 文字"将图片拖到此处，或点击上传"
- 支持 **拖拽多张图** + 点击文件选择
- 上传后下方显示缩略图列表（小图 + 文件名 + 删除按钮）

**② 参数区（左对齐，紧凑）**
- 检测模型：下拉框「YOLO-World（R0 · 官方权重）」「YOLO26n-seg（R1 · 自训回标）」
- 置信度阈值：滑块 0.05 ~ 0.9，默认 0.25，右侧实时显示数值
- 「开始检测」靛蓝按钮 + 清除结果按钮

**③ 结果展示区（占满宽度）**
- 顶部三模式切换 Tab：**检测框 / 实例掩码 / 语义分割**（与 5000 画布三模式对应）
- 中间画布：当前选中图片的检测结果，支持点击实例查看详情
- 右侧（或下方）实例列表：每个实例的 #序号 + 类别 + 置信度
- 多图时左侧有缩略图切换条，点击切到对应图的结果

**④ 进度条（检测中显示）**
- 点击开始检测后，按钮变"检测中…"，下方出现进度条 + 当前处理的图片名
- 完成后自动切到第一张图的结果

### 3.3 三模式渲染

复用 5000 `canvas/app.js` 的渲染思路，但简化为只读（不支持编辑）：
- **检测框模式**：画矩形框 + 类别标签 + 置信度
- **实例掩码模式**：画多边形填充 + 边界
- **语义分割模式**：按类别合并同色填充

使用原生 Canvas 2D 绘制，不引入第三方库。

### 3.4 实例详情面板

点击画布上的实例，右侧弹出详情面板（只读）：
- 序号：#N
- 类别：类别名（英文 + 中文）
- 置信度：0.893
- 底层 id：（R0 为 p+序号，R1 为 r1+序号，仅展示用）
- 面积：像素数
