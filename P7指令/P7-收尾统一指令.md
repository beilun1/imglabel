## 一、修 export.html（导出页校验过程态）

### 背景
`templates/export.html` 右上角「导出报告」状态标签存在**过程不体现**问题：
- 标签由服务端预渲染（`{{ '校验通过' if export.valid else '待校验' }}`），打开页面即显示"校验通过"；
- 点击「执行临时导出校验」时，JS 只改了按钮文字（"导出校验中…"）和 form-note，**没有同步改右上角 `exportState`**。

### 改法（只改这一个文件、就近一行，纯前端）
在 `C:\Users\H\Desktop\瑞翼二面\templates\export.html` 的 `<script>` 内，`btn.onclick` 处理器**开头**（`btn.disabled=true;` 之后）追加两行：
```js
const st=document.getElementById('exportState');st.textContent='校验中…';st.classList.remove('pass');
```
配合原有 API 返回后更新逻辑（`st.textContent=valid?'校验通过':'校验失败'; st.classList.toggle('pass',valid)`），形成 **校验中…（灰，无绿）→ 校验通过（恢复绿）** 的完整过程感。中途态去掉 `pass`（绿）类，避免"未完成却显绿"。
