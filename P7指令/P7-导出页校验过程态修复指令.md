# P7 · 导出页校验过程态修复（交付给 Qoder）

## 背景

导出页 `templates/export.html` 右上角「导出报告」状态标签存在**过程不体现**问题：
- 标签由服务端预渲染（`{{ '校验通过' if export.valid else '待校验' }}`），打开页面即显示"校验通过"；
- 点击「执行临时导出校验」时，JS 只改了按钮文字（"导出校验中…"）和 form-note，**没有同步改右上角 `exportState`**；
- 导致执行过程中右上角一直停在"校验通过"，API 返回后才更新 → 用户感觉不到"正在校验"的过程。

## 要求：只改一个文件、就近一行，纯前端

在 `C:\Users\H\Desktop\瑞翼二面\templates\export.html` 的 `<script>` 内，`btn.onclick` 处理器**开头**（`btn.disabled=true;` 之后）追加两行，把右上角状态标签切到"执行中"态：

```js
const st=document.getElementById('exportState');st.textContent='校验中…';st.classList.remove('pass');
```

配合原有的 API 返回后更新逻辑（`st.textContent=valid?'校验通过':'校验失败'; st.classList.toggle('pass',valid)`），即可形成 **校验中…（灰，无绿）→ 校验通过（恢复绿）** 的完整过程感。

## 为什么这样改

- 中途态去掉 `pass`（绿）类，避免"未完成却显绿"；完成后恢复绿，符合项目克制视觉规范；
- `document.getElementById` 与现有 JS 风格一致，无新增依赖/库/网络请求；
- 只影响展示层，不动导出逻辑、不动 dataset、不碰任何数据。
