## 任务：回标 → R1 人工修正 → R1 重导出 → R1 重训练 → 对比结果.csv

### 任务 1：回标脚本（用自训模型 best.pt 生成 R1 草稿）

新增 `reback.py`（或扩展现有 prelabel.py，但**不要动既有的 R0 预标注主流程**）：

- **只对“R0 未过审的预标草稿图”回标**：
  - 判定条件（全部满足才回标）：JSON 存在其 `source` 为 `prelabel`（或等效 R0 草稿标记）、无 `reviewed:true`、全部实例 `mark=="unchanged"`、**不含任何 `src:"reback"` 实例**
  - **硬性跳过**：153 张已过审图（有 `reviewed:true` 或任何人工 `mark!=unchanged` 或 source 非 prelabel）**一律跳过，md5 不许变**
- 用 `model/best.pt`（YOLO26n 分割微调版）对目标图推理，生成实例掩码：
  - 类别词表、顺序、英文名不得改（同任务书十类）
  - 掩码沿用画布 polygon 点集结构；`≥25px²` 孔洞用零宽桥缝进外轮廓（与 P3 同一表示）
  - 实例字段沿用 P3 JSON 约定：`id:"p0.."`、`cls`、`mark:"unchanged"`、`auto:true`、`conf`、`src:"reback"`（标记这是回标草稿）、`mask:{type:"polygon",points}`
  - 置信度阈值沿用 0.25（可 `--conf` 调整）
- **回标后 JSON 顶层**：`source:"reback"`、`modified_count:0`，否则其余字段与画布 save 兼容（image/width/height/instances）
- **幂等**：目标图已含 `src:"reback"` 实例的图跳过；可安全重复运行
- 输出统计：本轮回标张数、跳过张数、实例总数、平均/张、按类实例数、错误数
