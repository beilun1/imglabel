## 任务：实现预标注功能（prelabel.py + 后端 API + 前端进度条）

### 任务 1：prelabel.py 核心脚本
- 用 **YOLO-World**（`yoloworld.pt`）开放词汇检测 + **YOLO26n-seg**（`yolo26n-seg.pt`）实例分割，对 `data/curated/images/` 的 328 张图生成预标注草稿
- 类别 prompt 用十类英文原词（顺序即编号，**不得改**）：
  `person, chair, dining table, couch, tv, laptop, cup, bottle, potted plant, bed`
- **以 YOLO26n-seg 掩码为唯一真值源**（画布方案：掩码是真值，框=掩码外接矩形自动派生）；YOLO-World 检测作为补充：分割未覆盖但检测置信度 ≥0.25 的框，以框矩形作为占位掩码
- 置信度阈值可配置（默认 0.25）；**先跑 3 张子集验证质量，再跑 328 全量**
- 输出到 `data/annotations/{图名}.json`，结构必须与画布加载函数兼容（**先读 canvas/app.js 的 load/save 代码对齐字段**）：
  ```json
  {
    "image": "xxx.jpg",
    "w": 960,
    "h": 640,
    "instances": [
      { "id": 0, "cls": 0, "mask": [[x,y],...], "mark": "created", "auto": true, "conf": 0.82 }
    ]
  }
  ```
  - `auto: true` 标记所有预标注自动生成的实例（**P4 修正计数靠它区分"人工修改"与"自动生成"，必写**）
  - `mask` 为多边形点集（像素坐标），与画布多边形格式一致
- **幂等**：已存在 JSON 的图跳过不覆盖，可重复运行

### 任务 2：后端 API（app.py 集成）
- `POST /api/prelabel`：启动后台预标注线程（328 张，逐张处理，不阻塞请求）
- `GET /api/prelabel/status`：返回 `{ running, done, total, current_file, errors[] }`
- 任务进行中重复触发返回 409 或明确提示"运行中"

### 任务 3：前端进度条（列表页）

- 完成后自动刷新列表（标注状态徽章更新）
- 页面不卡顿，样式与浅色主题一致
