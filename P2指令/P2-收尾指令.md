## 任务：两项收尾（①选中高亮撞色修复 ②清理测试标注），完成后提交

你是接手本项目的代码开发工程师。项目是"人机协同图像标注系统"（Flask + Canvas）。上一轮你已完成调色板更换与橡皮擦按区域擦除，汇报被用户确认通过。现做两项收尾。

### 任务一：选中高亮色改为"白色主线 + 深色阴影"（不再撞类别色）

- 现状：`canvas/app.js` 中 `const SEL_COLOR = "#ffb020";`（第 14 行附近）——上一轮调色板把桌子改成了橙色 `#f97316`、瓶子改成黄色 `#eab308`，**选中高亮的橙色与这两个类别实色相撞**，选中橙色/黄色掩码时高亮看不清。
- 修改要求：
  1. `SEL_COLOR` 改为 `"#ffffff"`（白色），`SEL_SHADOW`（`rgba(0,0,0,.75)`）保持不变——现有 `strokeSelected`/`drawBox`/`drawMask` 已是"深色衬底 + 主线"双层描边，改为白线后：白色主线在**任何彩色掩码**上清晰，深色阴影保证在**浅色画布/原图**上也清晰；
  2. 检查所有使用 `SEL_COLOR` 的地方（选中框描边、选中掩码描边、选中标签 `drawTag` 底色等），确认换成白色后文字颜色自适应正确（`textOn` 会根据底色自动选黑/白字）；
  3. 不要动 `SEL_SHADOW` 的值，也不要动其它颜色。

### 任务二：清空 `data/annotations/` 下的测试残留标注

- 背景：目前处于 P2 阶段，`data/annotations/` 下只有开发/测试过程中保存的 JSON（如 `coco_10092.json` 等），**没有真实标注成果**。P3 预标注草稿、P4 人工过审都尚未开始，残留测试数据会污染后续统计与记录，需清空。
- 修改要求：
  1. 先 `Get-ChildItem data\annotations`（或 ls）列出当前文件，确认都是测试残留；
  2. 删除 `data/annotations/` 下所有 JSON 文件（保留目录本身）；
  3. 若删除后列表页徽章显示异常（如引用已删标注），确认应用能正常从"无标注"状态工作即可。
