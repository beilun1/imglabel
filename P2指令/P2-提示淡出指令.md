## 任务：将"空画布引导提示"改为"首次显示 3 秒后自动淡出消失"

你是接手本项目的代码开发工程师。项目是"人机协同图像标注系统"（Flask + Canvas）。当前 `canvas/app.js` 的 `drawEmptyHint()` 在画布没有任何实例时**常驻绘制**引导提示（如"在图片空白处按住左键拖拽，创建检测框"），用户觉得碍眼。现改为**自动淡出**。

### 现状（先读代码确认）

- `app.js` 约 493 行：`draw()` 末尾条件 `if (!live.length && !state.strokePts.length && !state.pendingPts.length && !state.editRect) drawEmptyHint(ctx);`
- `drawEmptyHint(ctx)`（约 497 行）按 `state.mode` 选文案，调 `drawCenterText(ctx, tips[state.mode], false)` 画在画布中央；
- `drawCenterText(ctx, text, isError)`（约 506 行）会 `setTransform` 后绘制半透明白底黑字长条；`isError=true` 时是红底错误样式。

### 修改要求

1. **行为**：进入标注页后，若画布为空（无实例等），引导提示**显示约 3 秒后自动淡出消失**；本张图会话内不再出现（切模式/缩放/平移后也不再出现）；**刷新页面或切到下一张图重新加载后重新出现**。
2. **淡出效果**：显示的前约 2.2~2.5 秒完全不透明，最后约 0.5~0.8 秒透明度从 1 渐隐到 0（可接受 0.3~0.5 秒的线性渐隐，视觉自然即可）。
3. **实现建议（可自行优化，但必须满足上述行为）**：
   - 在 `state` 增加提示显示时间戳（如 `state.hintUntil`、`state.hintShown`），在 `load()` 初始化时设置；
   - `drawEmptyHint` 内判断时间：超时则直接 return（不再绘制）；临近超时用 `ctx.globalAlpha` 渐隐后恢复为 1；
   - 注意：`drawEmptyHint` 结束前必须把 `ctx.globalAlpha` 复位为 1，避免影响后续绘制；
   - **不要改动 `drawCenterText` 的 `isError` 分支**——"图片加载失败"等错误提示仍要常驻显示，只有引导提示才淡出。
4. **约束**：
   - 只改 `canvas/app.js`，不改模板、CSS、后端；
   - 不改变任何标注交互逻辑；
   - 代码风格与现有文件一致（不写多余注释）。

### 验收标准（全部通过才算完成）

1. 启动服务（5000 端口被占用就先结束旧的 python.exe）→ 打开一张**未标注**的图：提示出现，约 3 秒后淡出消失；
2. 淡出后：滚轮缩放、切模式、平移——提示不再出现；
3. 按 F5 刷新该图：提示重新出现并再次淡出；
4. 打开一张**已标注**的图：全程不出现提示（保持原逻辑）；
5. 错误提示（如有）不受影响，仍常驻显示。
